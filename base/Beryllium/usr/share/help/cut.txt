Usage: cut OPTION... [FILE]
  or:  cut OPTION (piped input)

Print selected parts of lines from FILE (or the piped input).

  -d DELIM   use DELIM instead of TAB as the field delimiter
  -f LIST    select these fields (1-based): 1,3 or 2-5 or -3 or 5-
  -c LIST    select these character positions instead of fields
  -s         do not print lines that contain no delimiter
  -h         display this help and exit

Examples:
  cat /etc/passwd | cut -d: -f1      first field of every line
  cut -d, -f2-3 data.csv             second and third CSV columns
  cut -c1-8 dump.txt                 first 8 characters of every line
